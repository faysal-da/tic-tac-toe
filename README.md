# 🎮 Tic Tac Toe Game by faysal (Web)

A simple and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**. This project is beginner-friendly and runs directly in the browser without any dependencies.

---

## 🚀 Features

* ✅ Two-player mode (Player X vs Player O)
* ✅ Real-time turn switching
* ✅ Win detection logic
* ✅ Draw detection
* ✅ Restart game functionality
* ✅ Clean and minimal UI

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the game
* **CSS3** – Styling and layout
* **JavaScript (Vanilla JS)** – Game logic and interactivity

---

## 📂 Project Structure

```
index.html   # Main game file (includes HTML, CSS, JS)
README.md    # Project documentation
```

---

## ▶️ How to Run

1. Download or clone this repository
2. Open the `index.html` file in any web browser

No installation or setup required.

---

## 🎯 How to Play

* The game is played on a 3×3 grid
* Player **X** starts first
* Players take turns clicking on empty cells
* The first player to align 3 symbols (row, column, or diagonal) wins
* If all cells are filled with no winner, the game ends in a draw

---

## 🔄 Restarting the Game

Click the **"Restart Game"** button to reset the board and start a new match.
